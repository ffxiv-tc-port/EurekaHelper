# EurekaHelper

[EurekaHelper](https://github.com/KangasZ/EurekaHelper) 的台服移植版。禁地優雷卡專用的追蹤器與便利工具插件，介面仿照 ffxiv-eureka.com 社群追蹤器網站；也支援新月島的魔法甕尋寶。

## 指令

| 指令 | 說明 |
|---|---|
| `/eurekahelper`、`/ehelper`、`/eh` | 開啟／關閉主視窗 |
| `/arisu`、`/miniarisu`、`/mercy` | 顯示亞瑟羅王、複製魔花凱西、斯庫爾三隻 NM 的下次天氣時間 |
| `/etrackers` | 尋找目前所在資料中心、同副本的公開追蹤器 |
| `/erelic` | 開啟／關閉禁地兵裝進度視窗 |
| `/ealarms` | 開啟／關閉鬧鐘視窗 |

開啟「在「伺服器資訊」列顯示伺服器 ID」（預設關）時，資訊列會多一個優雷卡圖示（滑鼠指著看伺服器 ID），左鍵或右鍵都會開啟／關閉主視窗。

## 主視窗分頁

- **追蹤器**：加入或建立社群追蹤器，依區域分頁顯示各 NM 出現狀態，介面仿照官方網站；換到同區另一個副本時只有開了「自動建立追蹤器」（預設關）才會自動建新的
- **兵武塔 BA**：兵武塔專用簡化面板，追蹤未確認飛行物體／傷悲光靈魟戰況與塔內狀態
- **聖靈**：記錄已知聖靈在各區域的出現位置
- **變異怪物**：追蹤恆冰之地／湧火之地／豐水之地的環境適應、突然變異怪物天氣時段，並可用 Splatoon 在怪物身上標示
- **尋寶**：
  - 優雷卡：收集使用幸運胡蘿蔔（幸福兔事件後取得）時的方位提示，推算寶藏位置，透過 Splatoon 畫在畫面上並在地圖上插旗
  - 新月島：魔法甕 F.A.T.E. 後用魔法聖靈藥得到的提示，列出符合全部提示的已知財寶點，以淡色（可能）／實色（已確認）圓圈標出，並可畫到 Mappy 的地圖上
  - 選用：自動走向旗標（需要 vnavmesh，預設關；你按著移動鍵或滑鼠時先不送，停手後才送）
- **隱藏危險**（需另外啟用）：標記優雷卡／兵武塔內的隱藏陷阱與傳送門，分「可能有」與「已確認」兩種狀態，不含內建資料，需自行分類累積
- **設定**：主視窗與各項功能的細部設定，包含 NM 仇恨範圍顯示（需要 Splatoon，實驗性，預設關）
- **副本**：顯示目前優雷卡副本的伺服器 ID（此功能作者已停止維護，僅供參考，準確性不保證）
- **關於**：版本、指令、致謝等資訊

## 台服版的修改

- 新增新月島魔法甕尋寶：依提示篩出已知財寶點、Mappy 地圖標示、自動走向旗標；尋寶進行中與走向的目的地都以 IPC 提供給 BOCCHI（讓它先等尋寶走完、走路時繞開魔物）。
- 新增兵武塔分頁、幸運胡蘿蔔尋寶、變異怪物追蹤、隱藏危險標示、NM 仇恨範圍（Splatoon）。
- 追蹤器依區域分頁，連線在插件重啟後保留；即時串流斷線會自動重連。
- 自動上傳到 ffxiv-eureka.com 的動作全部預設關閉（含「自動標記 FATE 觸發」與自動建立追蹤器）。
- 追蹤器連線出錯不再讓遊戲結束。
- 遊戲改版後進區偵測的特徵碼對不上時，只停用伺服器 ID 顯示與進區自動開追蹤器，插件照常載入。
- 多處降低記憶體用量。
- 介面繁體中文化（用台服官方名稱）。

## 需要搭配的插件

- 選用：Splatoon（畫面標示）、vnavmesh（自動走向旗標）、Mappy（新月島財寶點畫在地圖上）、BOCCHI（會讀取尋寶狀態）

## 已知問題

「互動選項」設定為「喊話到聊天」且同時安裝 Chat 2 時，點擊聊天中的訊息連結會導致遊戲當機。

## 安裝

在 Dalamud 設定的「自訂插件庫」加入
`https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json`
並啟用，再從插件列表安裝。
